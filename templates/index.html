System Architecture & Model Specifications

Feature Extractor
HOG (Histogram of Oriented Gradients)
9 bins, 8×8 cell, 2×2 block, L2-Hys norm
Feature Dimension
900 numeric float32 features
Extracted from 48×48 normalized grayscale image
Classifier
Linear Support Vector Classifier (LinearSVC)
C = 0.35, class_weight = 'balanced', random_state = 42
Training Protocol
FER2013 Clean Split
Combined Train + Validation: 27,933 samples
Preprocessing Tool
MediaPipe + Pillow Pipeline
Face detect & crop -> Grayscale ('L') -> 48×48 resize
Target Classes
7 Discrete Facial Expressions
Angry, Disgust, Fear, Happy, Neutral, Sad, Surprise
